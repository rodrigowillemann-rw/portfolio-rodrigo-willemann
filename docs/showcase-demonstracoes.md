## Prints ou Imagens Recomendadas

Para fortalecer o portfolio, criar imagens de:

- dashboard de projetos com indicadores de prazo, custo e risco;
- matriz de valoracao de tecnologias;
- fluxo de analise automatizada de documentos;
- mapa ou tabela comparativa de indicadores urbanos;
- tela principal da plataforma DPP.

## Roteiro Curto para Video ou GIF

1. Mostrar o problema em uma frase.
2. Abrir o projeto ou notebook.
3. Executar a analise com dados sinteticos.
4. Mostrar o resultado principal.
5. Fechar com proximo passo ou aplicacao real.

## Mensagem-Chave

As demonstracoes devem mostrar que os projetos nao sao apenas ideias: cada um tem problema, publico, dados de exemplo, metodo e caminho de evolucao.
