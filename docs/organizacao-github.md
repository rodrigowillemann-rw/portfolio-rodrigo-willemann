## Padrao de Nomes

Use nomes curtos, claros e orientados ao tema do projeto:

- `dpp-platform-ai`
- `value-tech-valuation`
- `project-dashboard-analytics`
- `document-ai-analyzer`
- `urban-data-analysis`
- `research-project-manager`

## Padrao Minimo de README

Todo repositorio deve ter:

- descricao do problema;
- objetivo do projeto;
- tecnologias utilizadas;
- instrucoes de execucao;
- roadmap;
- status atual;
- link para prints, dashboard ou demonstracao quando existir.

## Acoes Recomendadas

- Adicionar descricoes curtas nos repositorios pelo GitHub.
- Fixar os projetos principais no perfil.
- Criar imagens ou capturas de tela para cada projeto demonstravel.
- Tornar publico apenas o que estiver pronto para representar bem o portfolio.
- Manter repositorios experimentais privados ate terem README, contexto e proximo passo claro.

## Narrativa Profissional

O portfolio deve comunicar uma combinacao de tres forcas:

- gestao de projetos e governanca;
- tecnologia, dados e IA aplicada;
- impacto em inovacao, industria, setor publico e sociedade.

Essa narrativa diferencia o portfolio de uma colecao de codigos soltos e aproxima cada projeto de problemas reais.
