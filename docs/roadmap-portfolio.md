## Criterio de Qualidade para Publicar um Projeto

Um projeto esta pronto para ser destacado quando tiver:

- README em formato de estudo de caso;
- dados ou exemplo executavel;
- demonstracao visual ou notebook;
- roadmap claro;
- status honesto do desenvolvimento;
- relacao explicita com sua narrativa profissional.
